# Minimal AI Data Assistant

A sleek, Bento-styled Streamlit web application that uses Groq LLM to convert natural language into executable Pandas code for instant data analysis.

## Setup

1. Open your terminal and navigate to this folder.
2. Install dependencies: `pip install -r requirements.txt`
3. Ensure your `groq-api.key` file contains your active API key.
4. Run the app: `streamlit run app.py`

## Usage
Upload the provided `sales.csv` and ask questions like:
- "Show me the average sales by city."
- "What is the most expensive product?"
